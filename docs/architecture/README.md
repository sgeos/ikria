# Architecture

> **Navigation**: [Documentation Root](../README.md)

Narrative descriptions of the system, one file per component or concern. Mark each point
as **Decided**, **Proposed** or **Open**, and say whether it is implemented.

- [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md): questions on the operator brief that must be
  settled before the design document is final.
- [`CAMPAIGN_PLAN.md`](CAMPAIGN_PLAN.md): what completing the career campaign means, the
  rules it keeps, and the order of its phases. Final, 2026-11-14.
- [`CAMPAIGN_SEQUENCE.md`](CAMPAIGN_SEQUENCE.md): the prospective order of research,
  purchases and upgrades, with the plan for science and funds through the early game.
  Proposed.
- [`AGENCY_RECORD.md`](AGENCY_RECORD.md): what the agency records, from vehicle
  specification sheets and mission documents to the program and its financials.
  Decided in scope, formats pending.
- [`HARNESS_DESIGN.md`](HARNESS_DESIGN.md): the bridge, the harness that runs Keleusma
  control loops, the mission controller and its MCP tools. Proposed, with the process
  layout and the bridge's repository decided.
- [`VTHL_PROGRAM.md`](VTHL_PROGRAM.md): the first-stage booster that takes off
  vertically and lands on the runway. A top priority.
- [`CREW_TRAINING.md`](CREW_TRAINING.md): the kerbal astronaut training program.
  Proposed.
- [`HAZARDS.md`](HAZARDS.md): the moons' orbital hazard bands, and the surface and
  environment hazards of each body.

- [Flight control](FLIGHT_CONTROL.md), the live verification runtime and operating procedure.
