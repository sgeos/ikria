# V0.1.0, Ground Work

> **Navigation**: [Roadmap](./README.md) | [Documentation Root](../README.md)

**Status.** In progress, defined 2026-11-14. This milestone is Phase 0 of
[`CAMPAIGN_PLAN.md`](../architecture/CAMPAIGN_PLAN.md). It builds the software and the
records that every later phase depends on, and settles the questions the design rests
on. No career flight happens in it.

## Done when

The harness flies the sandbox test craft `IkriaT0` through a hop and its parachute
landing, under Keleusma control in lockstep through the bridge. The record generators
produce the science ledger, the crew roster, the fleet registry and the facility levels
from the career save.
