# VR-0010, Live Keleusma Flight Control

> **Navigation**: [Verification](README.md) | [Mission M-0001](../missions/M-0001.md)

**Date.** 2026-11-17, Coordinated Universal Time.
**Author.** Codex.
**Status.** Development verification completed, with retained failures. No career clearance.

## Objective and method

Exercise the complete Rust bridge, Keleusma program and harness path on the previously
rehearsed IKR-TS-001B. The operator authorized the verification save and debug features.
No debug setter was used. Jebediah was recovered before every ignition. The empty
starting capsule had neither control authority nor a link, so continuous controls
were zero. Ignition and deployment were part-level verification instrumentation.

The software was developed and corrected between runs. The table is not a set of
identical qualification trials. The first telemetry-only checks found loss of exact
floating-point round trips. The first flight found the moving-frame velocity defect.
The second found touchdown bounce handling. Each became a regression test.

## Observed results

| Run | Samples | Maximum height above terrain | Duration in game seconds | Result |

| Hop 1 | 1,982 | 1,238.78 m | 39.62 | Article lost after no parachute deployment, I-0001 |
| Hop 2 | 6,737 | 1,240.07 m | 134.72 | Eight-part landing, software stopped on bounce, I-0002 |

| Coast abort | 6,798 | 1,239.19 m | 135.94 | Abort latched at sequence 669, settled touchdown, all eight parts recovered |

The abort request occurred during coast, not boost. Boost abort is tested offline,
not established by that live run. The abort program waited for safe descent before
deployment. Neither a solid-motor shutdown nor an emergency parachute deployment
outside the ordinary envelope is claimed.

The final normal and abort journals replay with 6,824 and 6,798 identical commands.
The monitor and pad-abort journals replay with their archived program body. Failed
journals are deliberately refused by the replay certification path. The successful
runs have consecutive samples approximately 0.02 seconds apart. This is observed
lockstep chronology, not a proof of deterministic game physics or hard real-time timing.

## Failures and corrections

[I-0001](../incidents/I-0001.md) records the lost article. Altitude changed while
velocity measured in the vessel-moving frame remained zero. The recovery probe also
used a default moving frame, so it did not detect descent. Explicit rotating-body
velocity and transformed angular rates corrected the bridge. The subsequent flights
show nonzero ascent and descent rates and successful deployment.

[I-0002](../incidents/I-0002.md) records the touchdown software fault. A brief landed
classification changed back to flying during a bounce. The program now returns to
descent, and completion requires one second of low-speed ground contact. Offline tests
exercise the bounce and the full completion interval.

## Evidence and reproduction

The [summary](data/flight-control/summary.json) gives per-run hashes, command events,
clock deltas, final samples, execution measurements and terminal outcomes. Raw journals
are gzip-compressed JSON Lines in [the data directory](data/flight-control/). The
hashes are over their uncompressed bytes. Bridge diagnostics, setup and recovery
records, source for the early program and pre-flight and post-flight context are
retained there. No craft or save file is redistributed.

```sh
python3 -I -B tools/phase0/summarize_flight.py \
  record/verification/data/flight-control/*.jsonl.gz
python3 -I -B -c 'import gzip,pathlib; pathlib.Path("tmp/replay-hop.jsonl").write_bytes(gzip.decompress(pathlib.Path("record/verification/data/flight-control/live-hop-3.jsonl.gz").read_bytes()))'
RUSTC_WRAPPER= cargo run -p ikria-harness --bin replay -- tmp/replay-hop.jsonl
```

The final gate covers 60 Rust tests and 13 offline Python tests in Ikria, plus three
bridge tests. None is ignored. The live runs above are additional observations,
not hidden opt-in tests counted by the offline gate. Local verification used macOS
and Rust 1.100.0. Remote continuous integration was not observed.

## Final state and limits

The game was left at the verification Space Center. Jebediah is available. Both final
articles were recovered intact. The real career and craft hashes match their initial
values. The five recorded debug flags were false before the flight series and after
it, with no debug setters called. Their state was not continuously sampled.

This establishes one complete normal lifecycle and one coast-abort lifecycle under
Keleusma control. It does not establish active attitude control, multiple vessels,
crew qualification, statistical repeatability, science completion, calibrated timing
admission or a campaign-valid command source for an empty starting capsule. T12's
original sandbox profile remains open. No career flight occurred.
