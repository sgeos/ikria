# Verification and R&D Reports

> **Navigation**: [Record](../README.md)

Each report documents one R&D or verification activity for later review. The format
is provisional, following the usual sections of a test report, until the blog line's
article on vehicle specification documents and their qualification records is
published. The reports name the Phase 0 experiments of
[`HARNESS_DESIGN.md`](../../docs/architecture/HARNESS_DESIGN.md) they cover.
